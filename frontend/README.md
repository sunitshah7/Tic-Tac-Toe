# Frontend

Angular client for the Tic Tac Toe exercise. See the [root README](../README.md) for the full
project overview, run instructions, API contract and design notes.

```bash
npm install     # first time only
npm start       # serves http://localhost:4200
npm test -- --no-watch
```

The API base URL lives in `src/environments/environment.ts` and defaults to
`http://localhost:5090/api`. Start the .NET backend before the frontend.
